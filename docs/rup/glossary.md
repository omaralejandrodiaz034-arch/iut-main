Glosario

- Bien: Elemento físico inventariable registrado en `bienes`.
- Dependencia: Unidad organizativa que contiene bienes.
- Unidad Administradora: Agrupación de dependencias bajo un organismo.
- Movimiento: Registro de una acción relacionada con un bien.
- Responsable: Persona asignada a una dependencia.
- Usuario: Cuenta del sistema que opera el aplicativo.
