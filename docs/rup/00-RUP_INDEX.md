# RUP Artifacts Index

Este índice agrupa los artefactos del proyecto según la metodología RUP y las fases de Inception, Elaboration y Construction.

## Estructura de documentos

- `VISION_RUP.md` — Documento de Visión.
- `01-Inception.md` — Resumen de la fase de inicio y entrega de artefactos.
- `02-Elaboration.md` — Resumen de la fase de elaboración y arquitectura base.
- `03-Construction.md` — Resumen de la fase de construcción, pruebas y despliegue.
- `Glosario_RUP.md` — Definición de términos clave del dominio.
- `Business_Case_RUP.md` — Caso de negocio y evaluación financiera.
- `Riesgos_Iniciales_RUP.md` — Lista inicial de riesgos y mitigaciones.
- `Plan_Desarrollo_Preliminar_RUP.md` — Plan preliminar de desarrollo.
- `SAD_RUP.md` — Documento de Arquitectura de Software.
- `Casos_de_Uso_Inicial_RUP.md` — Modelo inicial de casos de uso.
- `Casos_de_Uso_Detallado_RUP.md` — Modelo detallado de casos de uso.
- `Modelo_Analisis_Disenio_RUP.md` — Modelo de análisis y diseño.
- `Modelo_Datos_RUP.md` — Modelo de datos conceptual y lógico.
- `Modelo_Despliegue_RUP.md` — Modelo de despliegue.
- `Modelo_Pruebas_RUP.md` — Modelo de pruebas.
- `Manual_Usuario_RUP.md` — Manual de usuario y documentación de soporte.

## Notas

- Los artefactos se apoyan en la implementación existente en el repositorio, especialmente en los módulos de bienes, dependencias, organismos, movimientos, reportes y auditoría.
- El documento de visión ya se encuentra en `VISION_RUP.md`.
- La fase de construcción incluye el sistema de software ejecutable ya presente en el código fuente Laravel.
