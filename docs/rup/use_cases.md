Modelo de Casos de Uso (resumen)

Actores principales:
- Administrador (usuario con `is_admin`)
- Usuario operativo (Usuario)
- Auditor / Consultor

Casos de uso principales (implementados):
- Iniciar sesión / Autenticarse
- Administrar Organismos
- Administrar Unidades Administradoras
- Administrar Dependencias
- Registrar / Editar Bien
- Visualizar Bienes por Dependencia
- Registrar Movimiento de Bien
- Generar Reporte
- Gestionar Usuarios y Roles

Diagrama: ver `use_case_descriptions.md` para descripciones resumidas y trazabilidad.
