# Fase de Inicio (Inception)

## Objetivo

Definir el alcance del proyecto, identificar riesgos y determinar la viabilidad del negocio.

## Entregables de Inception

- Documento de Visión.
- Modelo de Casos de Uso (Inicial).
- Glosario.
- Caso de Negocio.
- Lista de Riesgos Inicial.
- Plan de Desarrollo Preliminar.

## Alcance de la fase

Esta fase busca responder:

- ¿Cuál es el problema que resuelve el proyecto?
- ¿Quiénes son los stakeholders principales?
- ¿Qué requerimientos son esenciales para el sistema?
- ¿Qué riesgos deben mitigarse primero?
- ¿Cuál es la propuesta de valor y retorno esperado?

## Requisitos esenciales identificados

- Registro y gestión de bienes.
- Estructura jerárquica de organismos, unidades y dependencias.
- Generación automática y única de códigos jerárquicos.
- Control de movimientos, desincorporación y reincorporación.
- Reportes y auditoría.

## Principales riesgos detectados

Ver `Riesgos_Iniciales_RUP.md`.

## Documento base

Ver `VISION_RUP.md`.

## Criterios de viabilidad

- El proyecto se considera viable si se confirma la infraestructura técnica, si los datos iniciales de bienes están disponibles y si existe un equipo de desarrollo con experiencia en Laravel.
- El sistema debe ser capaz de ejecutarse en un servidor institucional con PHP 8.2 y Laravel 12.

## Resultados

- Visión del producto asentada.
- Conceptos del dominio definidos.
- Riesgos críticos identificados.
- Plan preliminar de trabajo listo.
