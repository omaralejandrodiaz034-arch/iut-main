# Manual de Usuario - RUP (Resumen)

## Acceso al sistema

- Ir a la URL del sistema.
- Ingresar correo y contraseña.
- Si no tiene cuenta, contactar al administrador.

## Navegación básica

- Menú principal: Bienes, Dependencias, Organismos, Movimientos, Reportes.
- Buscar bienes por código, descripción o dependencia.

## Registrar un bien

1. Ir a `Bienes → Crear`.
2. Seleccionar `Organismo`, `Unidad Administradora` y `Dependencia`.
3. Confirmar el código sugerido o ingresar manualmente.
4. Completar los campos obligatorios y guardar.

## Transferir un bien

1. Seleccionar el bien en la lista.
2. Elegir `Transferir` y seleccionar dependencia destino.
3. Confirmar y registrar el movimiento.

## Desincorporar un bien

1. Seleccionar el bien.
2. Elegir `Desincorporar` y registrar motivo.
3. Generar acta si es necesario.

## Reportes

- Seleccionar filtros por organismo, dependencia, tipo o estado.
- Descargar en PDF o Excel.

## Soporte

- Contacto: administrador del sistema.
- Registrar incidencias y proporcionar capturas y pasos para reproducir.
